# NOTPONG

Um jogo inspirado no clássico Pong com uma estética arcade, desenvolvido exclusivamente com tecnologias web nativas.

## Objetivo do Jogo

- **Single Player**: Destrua todos os blocos brancos no menor tempo possível.
- **Multiplayer**: O objetivo é rebater a bola para que ela passe pela raquete do adversário. O primeiro jogador a marcar 10 pontos vence a partida.

## Regras e Controles

- **Jogador 1** (Esquerda): Usa as teclas `W` (Cima) e `S` (Baixo) para mover a raquete.
- **Jogador 2** (Direita): Usa as setas `UP` (Cima) e `DOWN` (Baixo) para mover a raquete. No modo Single Player, o jogador único utiliza as setas para se mover.

### Power-ups e Bolas Especiais (Modo Single Player)
Durante a partida no modo de um jogador, você encontrará bolas e blocos especiais com efeitos únicos:
- **Raquete Gigante (Ciano)**: Aumenta drasticamente o tamanho da sua raquete.
- **Bola Gigante (Verde)**: Aumenta a área de impacto da bola, facilitando a destruição de mais blocos.
- **Bola Bomba (Magenta)**: Causa uma explosão que destrói múltiplos blocos ao redor da área de impacto.
- **Multi-Ball (Amarelo)**: A bola se divide, criando várias bolas extras caóticas na tela.
- **Bloco Arco-íris**: Aparece e desaparece rapidamente. Se atingido, destrói todos os blocos restantes instantaneamente.

## Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando:
- **HTML5**: Estruturação semântica da página e uso do elemento Canvas.
- **CSS3**: Estilização utilizando classes utilitárias para layout responsivo, esquema de cores e animações visuais.
- **JavaScript**: Lógica completa do jogo, incluindo movimentação, física de colisão, sistema de pontuação, controle de estado e manipulação do DOM.

## Instalação e Execução

O jogo é totalmente funcional diretamente no navegador, sem a necessidade de instalação de dependências ou servidores locais.
Basta abrir o arquivo `index.html` em qualquer navegador web moderno para começar a jogar.
